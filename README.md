# Quick Notes

A simple website to write, save and delete notes quickly.

## Problem
To give students a proper locally run note taking app without any adds and data shared to a 3rd party app. also help them to organise there notes.

## Target Users
Students and anyone who needs quick personal notes.

## Features
- Add a note
- Delete a note
- Notes stay saved after refreshing the page (localStorage)
- Form validation (empty notes are not allowed)
- Responsive layout for phone and laptop
- Navigation menu (Home and About pages)

Note: the final product may include one or two extra features, only if I properly understand them and can implement them myself.

## Technologies
- HTML: page structure
- CSS: design and responsive layout
- JavaScript: add, delete, save and validate notes

## Pages
- index.html: Home (add and view notes)
- about.html: About the project
